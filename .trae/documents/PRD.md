# 记账App PRD（对照截图功能清单）

## 截图功能提取

### 图1 - 统计页
- [x] 顶部Tab：日常 / 月统计 / 年统计 / 资产统计
- [x] 月份切换：本月 / 上月 / 选择月份（带三角指示器）
- [x] 蓝色渐变汇总卡：月支出 / 月收入 / 月结余
- [x] 柱状图：收支统计，支出/收入/结余切换，绿色柱子，Y轴0-5.0k
- [x] 环形饼图：分类排行，支出/收入切换，左右图例
- [x] 分类排行列表：图标+名称+笔数+金额+百分比进度条

### 图2 - 资产页
- [x] 资产总览卡：总资产/日均成本，服役中/已退役/已卖出统计
- [x] 分类筛选：全部/吃穿住行/个人设备/小件设备
- [x] 状态筛选：全部/服役中/已退役/已卖出 + 排序
- [x] 2列资产卡片网格：状态标签+图片+名称+价格+天数+日均成本

### 图3 - 账户页
- [x] 净资产卡：净资产(元)/总资产/负债，眼睛切换显示
- [x] 快捷入口：报销/债务/理财
- [x] 账户分组：资金账户/充值账户/信贷账户/投资理财/其他，可展开

### 图4 - 日历页
- [x] 月历视图：年月标题+农历+今日按钮+收/支/余汇总
- [x] 日期选中高亮+当天账单列表
- [x] 空状态提示

### 图5 - 首页
- [x] 账本选择器
- [x] 收支概览卡：本月收入/支出/结余/总资产
- [x] 日期分组账单流水
- [x] 右下角悬浮记账按钮

### 通用
- [x] 底部6 Tab导航：首页/日历/账户/资产/统计/我的
